# User-Authentication-With-Json
🍏 FoodMart
A responsive e-commerce web application with an Admin Dashboard for managing products and a Storefront for customers to browse and purchase items.
Built using HTML5, CSS3, JavaScript, and Bootstrap for a clean and user-friendly interface.

📌 Features
Storefront (Customer Side)
🛒 Product browsing by categories

🔍 Search bar for quick product lookup

🛍️ Add to cart functionality with quantity updates

📱 Responsive design for all devices

Admin Dashboard
➕ Add, edit, and delete products

📂 Category management

💰 Price management

🖼️ Product image uploads (file input)

📊 Product listing table with editing options

🛠️ Technologies Used
HTML5 – Structure and semantic markup

CSS3 – Styling and responsive layouts

JavaScript (Vanilla) – Interactive elements and dynamic updates

Bootstrap 5 – Responsive design and prebuilt UI components
